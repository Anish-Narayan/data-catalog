# Payment Integrity Data Catalog

Welcome to the **Payment Integrity Data Catalog Demo**. This catalog provides a centralized repository for understanding various data assets across different clients, focusing on claims and payment integrity programs.

## Purpose

The primary goal of this catalog is to:
*   **Improve Data Discoverability:** Easily find information about clients, programs, and underlying data tables.
*   **Enhance Data Understanding:** Provide clear documentation on the purpose, fields, and relationships of each data asset.
*   **Support Data Governance:** Establish a single source of truth for data definitions.

## How to Use

*   **Navigation:** Use the left sidebar to browse clients and their associated tables.
*   **Search:** Type keywords in the search bar to quickly find relevant documents.
*   **Glossary:** Refer to the [Glossary](glossary.md) for common business terms and definitions.

## Glossary

-   [Claim](glossary.md#claim): A request for payment submitted by a provider.
-   [Member](glossary.md#member): An insured individual.
-   [Provider](glossary.md#provider): A healthcare professional or facility.
-   [Adjudication](glossary.md#adjudication): The process of reviewing a claim for payment.

# Welcome to the Payment Integrity Data Catalog

This catalog serves as a central repository for understanding the various data assets involved in our payment integrity processes. Use the navigation on the left to explore different clients, schemas, and tables.

## How to use this catalog:
*   **Search**: Use the search bar to quickly find documents by title.
*   **Navigate**: Click on the links in the left sidebar to view detailed information about each data asset.
*   **Explore**: Dive into schema and table details to understand data structures, fields, and their purpose.

This platform helps ensure data consistency, accuracy, and facilitates better insights into payment integrity.
